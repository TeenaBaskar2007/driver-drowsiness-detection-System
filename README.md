# Driver Drowsiness Detection System

A real-time Driver Drowsiness Detection System designed to help improve road safety by identifying signs of driver fatigue and drowsiness.

## Overview

Driver fatigue is a major contributor to road accidents. This project aims to detect signs of drowsiness and provide alerts to help prevent fatigue-related accidents.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- User-friendly interface
- Driver drowsiness detection interface
- Visual presentation of the system

## Project Structure

- `01index.html` – Main webpage
- `02style.css` – Styling and layout
- `03script.js` – JavaScript functionality
